# 데이 단타 (시가 매수 -> 당일 종가 매도) 연구

3년 일봉 패널 (시가 종가 기관 외국인) 로 "그날 아침 09:00 에 알 수 있는 정보만 써서 장중에 플러스인 종목군이
있는가" 를 검증한다. 오버나이트 전략 (`overnight/`) 이나 분봉 ORB (`intraday/`) 와 코드와 데이터를 공유하지 않는다.

## 데이터

`data/daytrade/daily.parquet` 가 이 모듈 전용 스냅샷이다. `data/panel.parquet` (다른 전략이 매일 갱신하는 원본) 를
읽기 전용으로 참고해 만들며 원본은 수정하지 않는다. float32 로 23MB. 재생성:

```bash
python -m daytrade.data build    # panel.parquet -> data/daytrade/daily.parquet
python -m daytrade.data info
```

09:00 에 알 수 있는 피처: 시가 갭 (시가/전일 종가. 실전은 08:59 예상체결가로 근사) 전일 등락률 전일 기관/외국인 순매수
20일 평균 |기관|+|외국인| 순매수 금액 (거래량이 없어서 유동성 대용으로 쓴다).

## 결과 (2023-09 ~ 2026-09 비용 18bp)

전 종목 장중 일평균은 -0.29% (비용 후) 다. 조건 없이 아침에 사서 저녁에 팔면 진다.

### 갭 하락 반등이 유일한 플러스 신호

| 시가 갭 | 장중 평균 | 승률 |
|---|---|---|
| -10% 이하 | +2.57% | 56% |
| -5 ~ -3% | +0.36% | 53% |
| -2 ~ -1% | +0.24% | 54% |
| 0 ~ +1% | -0.09% | 40% |
| +3 ~ +5% | -0.87% | 33% |
| +10% 이상 | -3.7% | 30% |

갭 상승 종목은 장중에 되밀리고 갭 하락 종목은 되오른다. 전일 등락률 수급 부호 가격대 요일은 이만한 차이를 내지 못했다.

### 그런데 유동성이 낮을수록 반등이 크다

기본 설정 (갭 -2% 이하 전일 동시 순매도 제외 갭 하락 큰 순 상위 30) 을 20일 평균 기관+외인 거래금액 밴드별로 나누면:

| 밴드 | 슬리피지 0 | 30bp | 50bp | 100bp |
|---|---|---|---|---|
| 0.1억 미만 | +1.31%/일 | +1.01% | +0.81% | +0.31% |
| 0.1 ~ 1억 | +1.01% | +0.70% | +0.50% | +0.01% |
| 1 ~ 5억 | +0.15% | -0.15% | -0.35% | -0.85% |
| 5 ~ 10억 | -0.16% | -0.46% | -0.66% | -1.15% |
| 10억 이상 | -0.25% | -0.55% | -0.75% | -1.24% |

기관과 외국인이 거의 거래하지 않는 종목에서만 수익이 나고 5억 이상에서는 사라진다. 이건 호가 스프레드가 넓은 종목의
시가가 매도 호가 쪽에 찍히고 장중에 중간값으로 돌아오는 반등 (bid-ask bounce) 의 모양이다. 실제로는 시가에 살 수 없고
한두 호가 위에서 사게 되는데 저가 소형주 한 호가가 0.3~1% 라 위 표의 슬리피지 열이 현실에 가깝다.

### 유동 종목에서는 아무 조합도 안 된다

20일 평균 5억 이상 종목만으로 갭 x 전일등락 x 수급 조합을 전부 봤다. 오버나이트 유니버스 (전일 동시 순매수 상위) 를
아침에 사서 저녁에 팔면 -0.4%/일. 전일 -5% 급락 후 동시 순매수 -0.9%/일. 갭 +3% 이상 -0.5~-1%/일.
갭 -3~-1% 동시 순매수가 -0.05%/일로 가장 덜 나쁜 정도다. 전부 마이너스다.

### 격자 스캔 (320 조합) 요약

갭 상한 4 x 유동성 밴드 4 x 정렬 5 x 상위 2 x 동시순매도 제외 2. 밴드별 평균 샤프: 0~5억 2.6 / 0.1~5억 1.6 / 1~5억 0.1 / 5억 이상 -1.3.
정렬은 갭 하락 순이 가장 좋고 (1.5) 동시 순매도 제외가 낫다 (1.0 vs 0.5). 5억 이상 밴드는 80 조합 전부 마이너스다.

## 판단

- 일봉만으로 되는 장중 롱 단타는 없다. 유일한 플러스 신호 (소형주 갭 하락 반등) 는 체결 슬리피지에 잠식된다
- 그래도 테스트하려면 "0.1~5억 밴드 갭 -2% 이하 상위 30" 을 페이퍼로 기록해 실제 체결가 대비 시가 차이를 재는 것이
  순서다. 슬리피지가 30bp 안이면 살아남고 50bp 를 넘으면 버린다
- 시장 장중 마이너스 드리프트는 롱이 아니라 오버나이트 (종가 매수 익일 시가 매도) 로 먹는 게 맞다는 기존 결론을 재확인했다

## 실행

```bash
python -m daytrade.test_daytrade                        # 합성 데이터 검증
python -m daytrade.backtest --sensitivity               # 기본 설정 + 밴드 x 슬리피지 표
python -m daytrade.backtest --slip-bps 50               # 슬리피지 반영
python -m daytrade.backtest --liq-lo 5e8 --liq-hi 1e13  # 유동 종목만
python -m daytrade.scan                                 # 320 조합 격자 -> results/daytrade/scan.csv (약 30분)
```

옵션: `--gap-max --gap-min --liq-lo --liq-hi --min-price --keep-both-sell --score {gap_down,prev_down,prev_up,liq,flow} --top --cost-bps --slip-bps`

## 실전 러너 (페이퍼 기본)

월요일 아침에 1200 종목을 사람이 볼 수는 없으니 `daytrade/live.py` 가 08:58:30 에 대신 본다.

1. 키움 예상체결등락률 하락 상위 (ka10029) 를 받는다 (전 시장 한 번에)
2. 감시 목록 (유동성 밴드 통과 종목) 과 교집합
3. 예상체결가가 전일 종가 대비 -2% 이하인 종목을 갭 큰 순으로 30개 -> 장전 시장가 매수 (시가 체결)
4. 15:20 시장가 매도 (동시호가 종가 체결). 15:45 종가로 평가해 카톡

```bash
python -m daytrade.live select          # 08:30~09:00 사이에 뭐가 잡히는지 본다
python -m daytrade.live buy             # 페이퍼 기록 -> results/daytrade_paper.csv
python -m daytrade.live buy --real      # 실주문 -> results/daytrade_log.csv
python -m daytrade.live eval            # 종가 평가 + 카톡

# VM 타이머 (오버나이트 타이머와 별도)
sudo cp deploy/aut-day-*.service deploy/aut-day-*.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now aut-day-buy.timer aut-day-sell.timer aut-day-eval.timer
# .env 에 DAYTRADE_ARGS="--top 30" (실주문은 --real 추가)
```

- 08:58:30 buy / 15:20 sell / 15:45 eval. 오버나이트 (08:35 매도 15:21 매수) 와 시간이 겹치지 않는다
- 스냅샷은 panel.parquet 가 더 새로우면 buy 직전에 자동으로 다시 만든다 (원본은 읽기만)
- 키움 ka10029 응답 필드명은 문서 기준으로 짰고 실계정으로 확인하지 못했다. 첫 실행은 `select --dump` 로 원본 첫 행을 보고 `expected_drops` 의 필드명을 맞춘다
- 권리락/배당락은 키움 등락률과 전일 종가 대비 갭 중 덜 떨어진 쪽을 써서 걸러낸다
- 페이퍼는 예상체결가를 매수가로 적는다. 실제 시가와 얼마나 다른지가 이 전략의 생사를 정하므로 실주문 로그의 체결가와 비교한다

```
daytrade/watchlist.py  다음날 아침 감시 목록 (밴드 통과 종목 + 발동가)
daytrade/live.py       08:59 선정 / 매수 / 15:20 매도 / 평가 (키움 + 카톡)
daytrade/test_daytrade.py
deploy/aut-day-*       systemd 타이머. deploy/run_daytrade.sh
```
